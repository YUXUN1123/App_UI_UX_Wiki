# App UI/UX Wiki 專案

🎓 HTML 教學簡報
👉 [點此直接瀏覽教學簡報](https://yuxun1123.github.io/App_UI_UX_Wiki/slides/index.html)

> **主題**：「為什麼有些 App 特別好用？——從使用者心理到 UI/UX 設計的完整解析」

本專案旨在為 UI/UX 初學者打造一套具備學術嚴謹度、實用性與可追溯性的 Obsidian 網狀知識庫，並為未來的互動式 HTML 教學簡報提供扎實的內容基礎。

---

## 核心架構方向

本專案採 **「7 篇理論 Wiki ＋ 3 個產品案例研究 ＋ 1 份 HTML 教學簡報」** 之整合架構：
- **7 篇理論 Wiki**：建立紮實的人因工程、認知心理學、互動效率與易用性評估理論基石。
- **3 個產品案例研究（`case_studies/`）**：深度剖析 Google Maps、Notion、Duolingo 的介面架構與設計得失，作為簡報之實例資料庫，不再作為獨立 Wiki 文章。
- **1 份互動式 HTML 教學簡報（`slides/`）**：萃取理論要點與實戰案例，專為初學者打造沈浸式教學體驗。

---

## 資料夾用途說明

- `AGENTS.md`：專案規範與 AI 代理行為準則（最高指導原則）。
- `00_Home.md`：知識庫總覽入口與閱讀導覽（MOC）。
- `rawpapers/`：原始文獻儲存區（僅收錄合法開放取用之全文資料）。
- `sources/`：來源中繼清單，包含 `sources_index.md`，詳列所有引文之 DOI、頁碼與來源限制。
- `01_Foundations/`：模組一：基礎概念與認知心理學（篇目 01~03：UI vs UX、心智模型、認知負荷與格式塔）。
- `02_Principles/`：模組二：互動機制與架構設計（篇目 04~05：互動效率與行為心理、資訊架構與流程）。
- `03_Evaluation/`：模組三：設計評估與診斷（篇目 06~07：介面反模式與暗黑模式、易用性測試與啟發式評估）。
- `case_studies/`：三大產品案例研究資料庫（Google Maps、Notion、Duolingo 案例研究與索引，供教學簡報直接使用）。
- `slides/`：預留之後製作互動式 HTML 教學簡報之檔案位置（目前暫不生成內容）。
- `assets/`：圖片與視覺素材儲存區。

---

## 專案工作流程階段

1. **第一階段**：建立專案骨架、管理規則與基礎文件結構。
2. **第二階段**：資料蒐集、文獻審核與 `sources/sources_index.md` 登錄。
3. **第三階段**：撰寫 7 篇理論 Wiki 知識文章與 `00_Home.md` 雙向連結網絡建立。
4. **第四階段**：完成三大產品案例研究（`case_studies/`），整合實務觀察與簡報素材摘要。
5. **第五階段**：萃取 Wiki 理論與案例研究內容，製作教學型互動式 HTML 簡報（`slides/`）。
